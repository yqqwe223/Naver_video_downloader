- 📊 **การแสดงผลข้อมูล**: แสดงชื่อเรื่อง, คำอธิบาย, ระยะเวลา, ความละเอียดที่มี, ข้อมูลผู้สร้าง, และวันเวลาของการเผยแพร่อย่างชัดเจน

- 📱 **ดีไซน์ตอบสนอง**: ประสบการณ์การใช้งานที่ปรับให้เหมาะสมกับเดสก์ท็อป แท็บเล็ต และสมาร์ทโฟน
- ⚡ **ประมวลผลรวดเร็ว**: การตรวจสอบความถูกต้องฝั่งไคลเอนต์ ร่วมกับการสื่อสาร API ที่มีประสิทธิภาพ
- 🔒 **ให้ความสำคัญกับความเป็นส่วนตัว**: ไม่บันทึก ไม่จัดเก็บข้อมูลผู้ใช้ ประวัติการสอบถาม หรือเนื้อหาวิดีโอใดๆ

### ติดตั้งในเครื่องท้องถิ่น (สำหรับนักพัฒนา)

```bash
# โคลนรีโพซิทอรี

cd naver-video-info
```

## 📖 คู่มือการใช้งาน

1. คัดลอกลิงก์วิดีโอจากแพลตฟอร์ม Naver ที่มีการตั้งค่าเป็น**สาธารณะ** (Naver TV, วิดีโอบล็อก, หรือสื่อที่ฝังใน Post)
2. วาง URL ลงในช่องป้อนข้อมูลของหน้าเครื่องมือ
3. คลิกปุ่ม "วิเคราะห์" และรอระบบเรียกคืนข้อมูลเมตาที่พร้อมใช้งาน
4. ใช้ข้อมูลที่แสดงเป็นข้อมูลอ้างอิงสำหรับการเรียนรู้ส่วนบุคคล งานวิจัย การวิเคราะห์สื่อ หรือการจัดการเนื้อหาดิจิทัลที่ถูกต้องตามกฎหมาย

> ⚠️ เครื่องมือนี้รองรับเฉพาะเนื้อหาที่เข้าถึงได้โดยไม่ต้องยืนยันตัวตนเท่านั้น วิดีโอที่ได้รับการป้องกันด้วยการตั้งค่าความเป็นส่วนตัว ต้องการการเข้าสู่ระบบ ต้องการการยืนยันอายุ หรือมีข้อจำกัดสำหรับกลุ่มผู้ใช้เฉพาะ ไม่สามารถประมวลผลได้ เนื่องจากข้อจำกัดทางเทคนิคและข้อกำหนดด้านการปฏิบัติตามกฎระเบียบ

- ✅ ไม่มีการแคช ส่งต่อ หรือจัดเก็บไฟล์วิดีโอหรือข้อมูลพฤติกรรมของผู้ใช้ใดๆ
- ✅ จำกัดวัตถุประสงค์เฉพาะสถานการณ์วิจัยที่ไม่ใช่เชิงพาณิชย์: การศึกษา, การวิจัยทางวิชาการ, มนุษยศาสตร์ดิจิทัล, การวิเคราะห์เนื้อหาสื่อ
- ✅ ไม่ให้ฟังก์ชันใดๆ ที่สามารถเลี่ยงการควบคุมสิทธิ์, การยืนยันอายุ, หรือกลไกความปลอดภัยของแพลตฟอร์ม
- ✅ ปฏิบัติตามข้อกำหนดการให้บริการและนโยบายการประมวลผลข้อมูลของ Naver อย่างครบถ้วน
