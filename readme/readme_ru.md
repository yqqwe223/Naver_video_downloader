# Naver Media Analyzer (Анализатор медиаконтента Naver)

> 🔍 Легковесный фронтенд-инструмент для образовательных и исследовательских целей, поддерживающий извлечение метаданных из общедоступного контента Naver

🌐 Онлайн-демо: [https://twittervideodownloaderx.com/naver_downloader_ru](https://twittervideodownloaderx.com/naver_downloader_ru)

---

## 📋 Описание проекта

Данный проект разработан в образовательных и исследовательских целях. Это легковесная фронтенд-утилита, предназначенная для помощи разработчикам и студентам в изучении методов извлечения структурированных метаданных из общедоступных страниц Naver (Naver Blog, Naver TV, Naver Post и др.) с использованием стандартных интерфейсов веб-превью и API структурированных данных.

> 🎯 Рекомендуемые сценарии использования:
> - Организация личных учебных материалов и сбор идей
> - Практика фронтенд-разработки и исследование методов извлечения веб-данных
> - Изучение структур мультимедийных метаданных
> - Архивирование общедоступного контента при наличии явного разрешения правообладателей

⚠️ **Важное уведомление**: Этот инструмент работает исключительно с **общедоступным контентом**. Он не предназначен и не имеет возможности для доступа к приватному контенту, контенту, требующему входа в систему, или любому контенту с ограничениями доступа.

## ✨ Основные возможности

- 🔗 **Интеллектуальное распознавание публичных ссылок**: Автоматически определяет URL-форматы общедоступного контента Naver (blog.naver.com, tv.naver.com, post.naver.com и др.)
- 🎬 **Поддержка множества типов ресурсов**: Извлекает метаданные для общедоступных видео, изображений, аудио и других медиафайлов (контент должен быть настроен на публичную видимость)
- 📐 **Отображение базовой информации**: Показывает тип медиа, размер файла, временную метку загрузки, информацию об авторе и другие общедоступные метаданные
- 📱 **Полностью адаптивный дизайн**: Оптимизированный пользовательский опыт на настольных компьютерах, планшетах и мобильных устройствах
- ⚡ **Архитектура с приоритетом клиентской части**: Основная логика анализа выполняется в браузере, уменьшая зависимость от сервера и повышая скорость отклика
- 🔐 **Дизайн с уважением к конфиденциальности**: Не регистрирует отправленные URL, не хранит результаты анализа и не собирает личные данные пользователей или информацию об учётных записях

## 🚀 Краткое руководство по использованию

1. Откройте платформу Naver (веб-версия или приложение) и найдите **общедоступный контент**, который вы хотите использовать
2. Скопируйте URL страницы из адресной строки браузера (пример: `https://blog.naver.com/username/123456789` или `https://tv.naver.com/v/12345678`)
3. Вставьте ссылку в поле ввода данного инструмента и нажмите кнопку "Анализировать"
4. Система извлечёт общедоступные метаданные и отобразит информацию о доступных ресурсах
5. Выберите предпочтительный ресурс, затем щёлкните правой кнопкой мыши по ссылке и выберите "Сохранить ссылку как..." для локального скачивания

> 💡 Советы по использованию:
> - Всегда проверяйте, что целевой контент имеет настройку видимости "Публичный"
> - Если анализ не удался, попробуйте обновить страницу или проверить подключение к сети
> - В учебных целях рекомендуется использовать Инструменты разработчика браузера (F12 → Network → Fetch/XHR) совместно с этим инструментом

## 🛠 Технические заметки по реализации (Для разработчиков)

> Обычные пользователи могут пропустить этот раздел

### Обзор архитектуры
```
Браузер пользователя → Клиентский модуль анализа → Публичная страница Naver / Интерфейс OEmbed → Извлечение структурированных данных → Отображение результатов
```

### Ключевые технические подходы
- Использует API `fetch` с соответствующей настройкой CORS-прокси для получения метаданных публичных страниц
- Анализирует теги Open Graph (`og:video`, `og:image`, `og:title` и др.) для обнаружения ссылок на ресурсы
- Использует структурированные данные (JSON-LD / Microdata) со страниц предварительного просмотра для дополнения медиаинформации
- Реализует двойную валидацию через регулярные выражения + парсинг DOM для надёжного распознавания ссылок

### Руководство по самостоятельному хостингу (Справочно)
```bash
# 1. Клонировать репозиторий (пример)
git clone https://github.com/yourname/naver-downloader-ru.git

# 2. Разместить статические файлы (настоятельно рекомендуется HTTPS)
#    - Vercel / Netlify / Cloudflare Pages (простая настройка, рекомендуется)
#    - Nginx + сертификат Let's Encrypt (вариант самостоятельного хостинга)

# 3. Пример настройки заголовков безопасности (Nginx)
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
add_header X-Frame-Options "DENY";
```

> 🔐 Лучшие практики для развёртывания в продакшене:
> - Всегда включайте HTTPS для предотвращения атак типа "человек посередине"
> - Реализуйте ограничение частоты запросов (rate limiting) для предотвращения злоупотреблений
> - Избегайте раскрытия чувствительной логики анализа, которая может быть использована во вред

## ❓ Часто задаваемые вопросы (FAQ)

**В: Почему появляется сообщение "Не удалось получить контент"?**  
О: Возможные причины: ① Ссылка указывает на приватный контент или контент, требующий аутентификации ② Контент был удалён или настроен как "Только для участников" ③ Naver временно изменил структуру страницы ④ Ограничения сети или проблемы с CORS. Решение: Проверьте публичный статус → Попробуйте в другой сети → Подождите и повторите попытку.

**В: Содержит ли скачанное видео/изображение водяные знаки?**  
О: Этот инструмент возвращает оригинальные URL ресурсов, предоставляемые официальной инфраструктурой Naver. Наличие водяных знаков полностью зависит от настроек пользователя, загрузившего контент. Этот инструмент не добавляет, не удаляет и не изменяет никакие водяные знаки или встроенные отметки.

**В: Поддерживается ли пакетная обработка для истории контента Naver Blog/TV?**  
О: Текущая версия ориентирована на анализ отдельного контента для обеспечения стабильности и соблюдения нормативных требований. Для пакетных операций, пожалуйста, сначала убедитесь, что ваш сценарий использования соответствует [Условиям использования](https://terms.naver.com/termOfService.naver) Naver в отношении ограничений частоты и использования данных.

**В: Собирает ли этот инструмент мои данные об использовании или информацию об учётной записи Naver?**  
О: Нет. Это чисто статический фронтенд-проект без ведения журналов на бэкенде, аналитических скриптов или отслеживания на основе куки. Вся обработка происходит локально в рамках вашей браузерной сессии, и вход в систему не требуется.

**В: Можно ли анализировать приватные публикации Naver Cafe или содержание личных бесед?**  
О: Нет. Этот инструмент поддерживает исключительно **ссылки на публичные страницы**. Анализ приватных публикаций, внутреннего контента Cafe или ресурсов, требующих входа в систему, технически не поддерживается и этически не рекомендуется. Это отражает нашу фундаментальную приверженность защите приватности пользователей и соответствию продукта.
