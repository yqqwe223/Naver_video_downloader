## 📋 Project Overview

**Naver Video Info Tool** is a lightweight web application designed to analyze and retrieve metadata from **publicly accessible** video content on the Naver platform (including Naver TV, Naver Blog videos, and Naver Post embedded media). This tool assists users, researchers, and digital archivists in obtaining technical information about videos—such as title, description, duration, available resolutions, uploader information, and publication timestamp—without interfering with platform infrastructure or bypassing any security mechanisms.

### ✨ Key Features

- 🔍 **URL Analysis**: Support for entering publicly accessible Naver video URLs to query associated metadata
- 📊 **Metadata Display**: Clear presentation of video title, description, duration, available resolutions, creator info, and publish timestamp
- 🌐 **English Interface**: Full English language support with clear, professional UI/UX design for global users
- 📱 **Responsive Design**: Optimized experience across desktop, tablet, and mobile devices
- ⚡ **Efficient Processing**: Client-side validation combined with optimized API communication for fast response times
- 🔒 **Privacy-First Approach**: No storage of user data, query histories, or video content at any stage

## 📖 Usage Guide

1. Copy the URL of a **publicly accessible** Naver video (Naver TV, Blog video, or Post-embedded media)
2. Paste the URL into the input field on the tool's web interface
3. Click "Analyze" to retrieve available metadata
4. Use the displayed information for personal reference, academic research, media analysis, or compliant digital content management

> ⚠️ This tool works exclusively with content that is publicly accessible without authentication. Videos protected by privacy settings, requiring login, age verification, or restricted to specific user groups cannot be processed due to technical limitations and compliance requirements.

## ❓ Frequently Asked Questions

**Q: Is this tool free to use?**  
A: Yes, completely free. This project is released under the MIT open-source license, and we welcome legitimate, compliant use for learning and research.

**Q: Are video files temporarily cached on servers?**  
A: No. The entire process is purely metadata querying—no media files are transmitted, cached, or stored at any stage.

**Q: Does it support private Naver videos or age-restricted content?**  
A: No. For technical feasibility and legal compliance reasons, only fully public content is supported.

**Q: Is API documentation available for integration?**  
A: Internal API specifications may be provided as technical reference materials upon formal request from accredited academic or research institutions. Please contact the maintenance team for details.

**Q: Does using this tool require a Naver account login?**  
A: No. Metadata queries for public content are processed without authentication, and no user account information is ever requested or stored.

**Q: Which Naver video formats are supported?**  
A: The tool supports common public video formats on Naver, including Naver TV videos, Blog-embedded videos, and Post-embedded media. New formats are continuously evaluated and integrated when technically feasible.
